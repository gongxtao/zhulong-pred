# 烛龙 ZHULONG · 设计与交接说明（浅色 · 决策先行一栏多层版）

> 文件：`zhulong.html`（单文件，ECharts CDN，零构建）
> 产出日期：2026-08-28 · 状态：结论主导决策层定稿并实测通过，待接真数据

## 一句话

不是仪表盘，是**调度员的驾驶舱 + 一台可以拨动时间的机器**：别人展示预测曲线，烛龙让评委亲手拨动时间、亲眼验证预测。

## 信息架构原则（为什么是这些数据）

页面按**用户问题的时间序列**组织，每个模块必须回答其中一个问题，回答不了的元素不占屏位：

| 问题 | 回答模块 |
|---|---|
| 现在正常吗？（秒级） | 状态条「现在/偏差」格 + 偏差副带 |
| 接下来 24h 要准备什么？ | 状态条「今日峰」格 + 右栏 01 决策卡 + 主图预备窗 |
| 这个预测可信吗？ | 状态条「可信」格 + 右栏 03 审计卡 |
| 为什么是这个值？ | 右栏 02 归因卡（温度贡献 = Δ温度 × 灵敏度，可复算） |
| 过去表现如何？ | 时光机回放 + 极端日排行 + 热力图 |
| 哪个区域是主因？ | 底部区域对比 |

**每个数字都带参照系**：当前负荷 vs 昨日同时、峰值 vs 近30日均值、预测 vs 历史极值线、误差 vs 标称覆盖率。孤立的数字没有意义。

## 布局（决策先行 · 一栏多层 · 文档流自然滚动）

```
顶栏（吸顶）：烛龙 identity · 区域切换 · 美东时钟 · LIVE · 演示按钮
⓪ 决策层（结论主导）：⚡建议动作 ·「预备窗 16:00–19:00 内，预备 2,700 MW 调峰资源」(26px 唯一主角)
   依据行：日峰 P50→P90 · 距纪录/较30日 · 爬坡 · 区间校准✓ · [查看审计↗]（左色条=风险等级）
   设计反思：数字大字版会把"建议"压成配角（展示流）；结论句才是决策流的产品差异点。
   已删除不可解释的「置信分」，替换为可验证证据链（区间校准 + 审计链接）。
① 状态层（四格对等醒目）：现在│偏差│今日峰(P50→P90@时刻+距纪录)│可信(MAPE+P90命中)
② 主线层（全宽时间脊柱，默认 3 天视窗）：
   实际(青)·昨日(灰)·NOW·预测扇形·上帝视角·历史极值线·预备窗
   峰值标注两行钉在图上：日峰 P50 xx · 时刻 ／ 最坏 P90 xx · 建议备 xx MW
   [温度带｜偏差带] · 表格式图例 · 频率句
③ 证据层（两张扁卡横排，高度互不影响）：为什么·归因 │ 可信·审计
探索层：时光机（14 年胶片 + 可拖 NOW + 极端日快捷） → 底部抽屉（区域/极端日/热力图）
（口径 = 主图 ⓘ 弹层，页面无展开卡——任何交互都不会改变布局高度）
```

**框架原则**（与用户对齐定稿）：页面第一眼 = 「要做什么」（决策层，倒金字塔）；
状态四格紧随其后且对等醒目、不被弱化；重点由全宽大图 + 峰值标注承担，不靠压暗别人。

## 视觉系统（浅色，全部经 CVD 六项验证）

- 背景 `#F5F7FA` · 卡片 `#FFFFFF` · 墨 `#0F172A/#475569/#7C8DA6`；浅色下**零发光**，层次由线宽（主曲线 3px）+ 色深 + 留白承担
- 实际 `#0891B2` · 预测 `#C2620A`（protan ΔE 20.2）；区域色 AEP `#0891B2` / DAYTON `#7C3AED` / DOM `#DB2777`（ΔE ≥ 15）
- 浅色的场地理由：8/30 游园会+路演为亮环境投影，浅色可读性优于深色
- 频率句保留衬线体（叙事声音），数字一律无衬线正比字（大数）/等宽（表格与轴）

## 演示剧本（六幕 ≈ 3.5 分钟）

纵深（14 年热力图）→ 节律（区域对比）→ 推演（参照系齐全的 fan chart）→ **验证（极涡重演，预测与真实对质）** → 自证（覆盖率审计）→ 落地（换省级数据即生产系统）。

## 数据替换契约（接 Supabase / 真模型）

原型数据为形态校准的仿真（真实 PJM 量级 + 2014 极涡/2012 热浪）。替换点集中在：

1. `loadAt(zone, ts)` → 查询/缓存 `energy_hourly` 小时值
2. `buildDaily()` → 按日聚合查询（或物化视图）
3. `forecastAt(zone, originTs)` → 真模型契约 JSON：`{ts, p10, p25, p50, p75, p90}[]`
4. `BT`（回测）与 `CAL`（残差标定）→ 真模型离线回测结果喂入；`RECORD` → 真实历史极值

其余渲染/交互层不动。真模型就绪前，页面内相似日基线 + 残差经验分位标定本身就是可讲的 Baseline（GEFCom2014 冠军范式的轻量实现）。
