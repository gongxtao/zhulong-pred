# DESIGN.md — 烛龙夜航（深空蓝 × 电流青 × 峰值琥珀）

> 与烛龙决策台产品同源：青/琥珀沿用产品「actual / fc」系列色 `#0891B2` / `#C2620A`，亮墨 `#E9F0FB`，底色取产品深空蓝 `#0B1730`。
> 图表系列色对已过 dataviz 六项验证（深底 CVD ΔE 20.2、对比度全 ≥3:1），作为本 deck 唯一系列色对。
> 本 deck 视觉全为**结构化元素**（曲线、流程、界面帧、图表），按通用设计原则 §5 允许 SVG / Chart / Box+Text 构建，无摄影类配图。

## 0. 设计宪法摘要（硬门禁）

- 每页 ≥1 个视觉锚点；L1 主视觉占 B 区 ≥30%（图表页 ≥50% 元件总面积）
- 常规页留白 ≤35%；P1 / P6 / P7（hero / peak 页）允许 40%，且留白围绕焦点
- 相邻页版式不得重复；每页与上一页视觉重量显著差异
- 色彩面积：主色（底）≤60%，辅（面板/线）≤30%，强调 ≤10%（P6 峰值页琥珀可达 15–20% 爆发）
- 全篇仅 4 个 hex + 其 rgba 透明变体；仅 2 套字体家族

## 2. 色彩系统（4 hex + rgba 变体策略）

| 角色 | 值 | 用途 |
|:-|:-|:-|
| 底 · 深空蓝 | `#0B1730` | 全篇页面底色；SVG 曲线底、图表 background 底 |
| 墨 · 亮墨 | `#E9F0FB` | 标题 / 正文主色；面板 = `rgba(233,240,251,.05)`，细线 = `rgba(233,240,251,.14)`，次级文字 = `rgba(233,240,251,.62)`，弱文字 = `rgba(233,240,251,.40)`，网格线 = `rgba(233,240,251,.05)` |
| 主强调 · 电流青 | `#0891B2` | 流程线、动态系列、Agent 中心节点、标题短横线、L3 页脚方点；glow 用 `rgba(8,145,178,.15~.30)` |
| 次强调 · 峰值琥珀 | `#C2620A` | 只给焦点：风险标记、未预见峰值点、active 版本节点、P6 巨型数字 −5.6%、金句下划线；警示底 `rgba(194,98,10,.10)` |

- **语义映射（图表与流程沿用产品 actual/fc 语义，已过 CVD 验证）**：实际/动态/持续学习 = 深青 `#0891B2`；预测/静态/旧 = 琥珀棕 `#C2620A`；风险与焦点 = 琥珀棕的强调用法（实心/发光）。两色 ΔE 20.2（protan 最差视角），亮度带、彩度下限、表面对比全通过。
- **渐变方案**：① 青光晕 `radial-gradient(circle, rgba(8,145,178,.20) 0%, transparent 70%)`——P3 Agent 节点、P6 巨型数字背后；② 琥珀光晕 `radial-gradient(circle, rgba(194,98,10,.22) 0%, transparent 70%)`——P6 数字与 P1 峰值点；③ 卡片头 `linear-gradient(90deg, rgba(8,145,178,.22) 0%, rgba(8,145,178,.02) 100%)`。
- **半透明策略**：面板叠在底色上用墨的 .05–.08；SVG 网格 .05；元素重叠时底层 opacity .15–.30；图表 background 用 `#0B1730` 纯色（Chart 文本色仅纯色）。

## 4. 信息密度门禁

- 内容页（P2–P5）：标题+正文+L1 图，正文 ≥170 字，L1 占 B ≥30%
- 数据页（P6）：标题+双图+洞察，正文 ≥120 字，图组占 B ≥50%
- 封面 / 结尾（P1/P7）：≥20 / 30 字 + 主视觉 B ≥35%
- 卡片填充率 ≥85%；尾部元素 `marginTop:'auto'` 钉底；横排兄弟卡三段 y 向对齐
- 留白上限：常规 35%，P1/P6/P7 允许 40%（围绕焦点，非均匀散布）

## 5. 配图系统

- 全篇 L1 均为结构化 SVG / Chart / Box 界面帧（无摄影图）：
  - P1 负荷曲线底图：SVG path 双线（实际=青实线，预测=灰蓝虚线），实际峰值超出预测段的区域琥珀填充 + ▲峰值点 + 骑线风险链文字
  - P2 流程带：SVG 圆角节点 + 青色箭头 + 琥珀旁注块
  - P3 中心辐射：SVG 中心圆（Agent 青光晕）+ 四象限弧布节点 + 连线
  - P4 双泳道：上泳道青色闭环（箭头回环），下泳道灰蓝直线，active 节点琥珀发光、竖向虚线连接两泳道
  - P5 三帧界面：Box 构建的深底「终端窗口」三联（顶栏圆点 + 界面内容），帧间青色 →
  - P6 Chart×2：单类别双系列横向条形（静态=灰蓝，持续学习=青），Menlo 数据标签
  - P7 双路径汇聚：SVG 两条并行泳道汇入中央金句光晕
- L3 母版徽标：C 区左侧「烛龙 ZHULONG」+ 青方点，全篇位置一致。
