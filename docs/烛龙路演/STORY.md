# STORY.md — 烛龙路演（7 页 / 5 分钟 / 投资人 + 产业客户）

## ① 意图块

- **目标受众**：贵州黑客松赛道二路演现场评委——投资人与产业客户（电网公司、电科院/数字电网研究院），5 分钟限时路演。
- **核心目标**：讲完让观众相信——我们卖的不是更大的预测模型，而是让 Agent 可靠工作的 Harness：把「模型失效后只能重新立项」的一次性交付，变成可持续运营的学习能力。记住一个数字：**持续学习让误差再降 5.6%**。行动召唤：以科技项目/影子验证形式合作，而非购买一次性交付。
- **PPT 长度**：7 页（5 分钟）。Hero 配额 2 页（封面 + 结尾），占 29%。
- **视觉调性**：深空科技 / 暗夜发光 / 产品同源（决策台暗色主题）/ 克制锐利。
- **内容边界**：必讲 = 风险链开场、王工痛点、Harness 定义、双闭环、产品演示、5.6% 实证、100 天路径。不讲 = 模型内部结构、训练超参、团队介绍（大纲未含）。禁碰 = 生产环境承诺——验证集数据必须带脚注。

- **结构**：单幕剧 7 页，无目录、无章节扉页（5 分钟路演不设目录页，大纲亦未设）。目录↔扉页契约：N/A（0 目录 = 0 扉页）。
