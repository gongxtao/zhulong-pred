- 项目数据：Supabase `public.energy_hourly` 表，PJM 三区域（AEP/DAYTON/DOM）2004-2018 小时级负荷 + ERA5 气象特征，共 358,737 行；DOM 区 2005-05 起数据（少约 5,000 行），跨区对比需裁齐公共区间；load_mw 为估算平均功率；天气为区域加权代理非实测；表已启用 RLS。
- 四路并行深度调研完成：①电网运营商界面（PJM/CAISO/AEMO/ENTSO-E/EIA）②时序可视化与不确定性标准（TimeViz/fan chart/Plotly 误差带）③商业产品与 Kaggle 范式（Amperon/Verdigris、GEFCom2014）④交互设计模式（range selector/zoom/small multiples）。
- 核心结论：官方电网界面几乎不画不确定性带，预测区间可作差异化亮点；行业共识三层架构 = KPI 卡行 → 历史+预测主图 → 区域对比+误差明细；fan chart 标准画法（历史实线/预测虚线/50·80·95% 嵌套浅色带/forecast origin 竖线）；3 区域同量纲用叠加折线+图例显隐（small multiples 作备选）；ECharts/Plotly 已具备全部所需交互（range selector、overview slider、十字线、联动）。
- 已产出推荐页面信息架构图（Z 型三层布局）并展示给用户。
- 下一步候选：页面信息架构文档 / HTML 高保真原型（ECharts）。
- 用户反馈"要真正深度调研，不是设计开发"→ 二轮深挖：五路并行、全部一手来源，产出《docs/load-forecast-ui-research.md》深度调研报告。
- 二轮关键发现：①电力负荷展示无正式标准（IEC CIM 只管数据模型、NERC 无 UI 规范），准标准=折线(Cleveland-McGill)+fan chart(BoE)+频率句标注(认知实证)+校准验证(GEFCom pinball)+人因(ISO 9241-110)；②fan chart 原始方法学(Britton 1998)：10% 步进、众数中心、覆盖 90%、尾部留白、色深编码概率密度；现行 BoE 为 30/30/30=90% 对称结构+频率句图注；③"中心线/点预测被过度信任"是跨领域最强实证共识(S9 飓风锥/S7 公交/S2)，主图须弱化中心线；④商业产品=决策流(置信分+告警+基准对比)，官方/开源=展示流；⑤ERCOT NOW 竖线+左实右虚、CAISO/PJM 口径成熟度标注、robikscube 月→周→最差日→最佳日 EDA 顺序可复用；⑥反模式清单 8 条(点预测过强/单层区间/误差条/扇区100%/裸百分比/概率词无数值/双轴滥用/区间不校准)。
