## 它解决什么问题

负荷预测的难点不是画一条曲线，而是**让调度员敢用它做决策**。烛龙把「预测」做成「决策台」：

1. **告示 → 仪表 → 机器**的层级：最顶一行给出建议动作（预备多少 MW、哪个时段），中间四格回答
   「现在/偏差/今日峰/可信吗」，主视觉是可拖动的时间机器——三者各司其职，不堆数字。
2. **预测是区间，不是线**：P10–P90 概率带像台风路径圆锥，随时间张开（越远越不确定）。
   调度底线用 P90 上界，每一档数字都可由页面内数据复算。
3. **预测接受审计**：P90/P50 命中率、MAPE、vs 持久性基线，全部页面内实时回测，不预设数字。
4. **诚实展示盲区**：把时间拨回 2014 极地涡旋——相似日模型 23.14% 落后于持久性基线 17.02%，
   页面如实展示"天气突变段我们不行"，这正是接入气象预报的论据。**知道自己什么时候不行，才敢在行的时候被信任。**

## 核心交互

- **时光机**：拖动胶片上的 NOW，回看任一天的「当时预测 vs 真实后续」对质（上帝视角可开关）；
  拖到最右段松手即回到实时。
- **实时对账（SWR）**：页面内嵌真数据快照实现秒开；查看任何历史段时按视窗实时查询 Supabase
  生产库校准（toast + 网络面板可见真实请求，同一视窗不重复查）。
- **三级数据源兜底**：在线 Supabase → 内嵌快照（断网可用）→ 内置仿真，演示永不翻车。
- **双主题**：浅/深两套色板均通过 CVD（色觉障碍）六项验证；默认深色。
- **演示六幕**（按 `D`）：纵深 → 节律 → 推演 → 验证 → 自证 → 落地，约 1 分钟讲完整个故事。

## 快速开始

### web 正式工程（主交付物）

```bash
cd web
npm install
npm run dev -- --port 3100        # http://localhost:3100
```

- 环境变量 `web/.env.local`：`NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY`
  （anon 公开只读 key，安全边界 = RLS 策略；service_role 密钥绝不入库）。
- 一键回归断言（30 项：秒开计时 / 基线数字 / 时光机 / 实时校准请求 / 离线兜底）：

```bash
cd web && node scripts/verify.mjs
```

### 原型（单文件，spec 与提交兜底）

```bash
cd docs/prototype && python3 -m http.server 4173   # http://127.0.0.1:4173/zhulong.html
```

## 架构

```
┌─ 表现层  Next.js 16 + React 19 + TypeScript + ECharts 6（React 只做静态骨架，命令式引擎接管渲染）
├─ 数据层  store 唯一后端：hours/daily/pred/cal/model + 实时校准溯源（liveDays/livePredOrigins）
│          boot = 快照秒开(~1s) → 后台同步近窗/日峰/预测 → 收敛在线基线
│          按需 = ensureWindow 视窗实时校准（缺失或快照来源都发真实查询）
├─ 预测层  生产模型注入（pred_static 日前起点按偏移重索引，≤24h）+ 相似日分位数基线（25–48h 兜底）
│          + 残差经验分位标定（CAL）+ FC_CACHE
├─ 评估层  滚动 28 起点 × 24h 回测（MAPE/cov90/cov50）+ 持久性基线对比 + 本段重演回测
└─ 数据库  Supabase（PostgREST）：energy_hourly ∪ energy_hourly_future + energy_daily 视图
           + pred_static 回测 + model_versions/training_trials 模型注册
```

- 快照再生成：`ZL_SKEY=<service_role> node scripts/build-snapshot.mjs`（密钥只走环境变量）。
- Supabase 库结构见 `data/README.md`。

## 数据与方法口径（诚实声明）

- **负荷**：PJM 负荷区（AEP / DAYTON / DOM）小时级估算平均功率（MW），2004-10 至 2018-08 真值
  （真实历史 + 模拟未来流）；区域非单一城市，换省级电网分区即可迁移。
- **气象**：ERA5 再分析区域加权真值（气温/湿度/降水/风速），非单站实测。
- **时间**：入库 UTC，展示统一美东 EST（UTC−5）。
- **预测**：0–24h 为生产模型（梯度提升回归，Supabase 注册、579 日起点回测标定分位带）；
  25–48h 为相似日基线延伸（按目标日同星期，无未来信息泄露），不入审计口径。
- **当前模型不直接消费气象预报**——天气突变日误差如实放大（见 2014 极涡重演），是已知盲区与改进方向。
- 页面内每一个数字均可由页面内数据复算；演示模式中无预设数字。
